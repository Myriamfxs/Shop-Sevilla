THE CANNABIS SHOP · PAQUETE PARA HOSTINGER

1. Descomprime el archivo ZIP en tu ordenador.
2. Sube el CONTENIDO de la carpeta (no la carpeta contenedora) a public_html desde el Administrador de archivos de Hostinger.
3. Conserva el archivo .htaccess: permite abrir directamente /cookies, /privacy y /aviso-legal.
4. Activa el certificado SSL para tu dominio desde Hostinger y comprueba las cuatro rutas anteriores.
5. Las imágenes se incluyen en la carpeta images del paquete, por lo que no dependen de servicios externos.
